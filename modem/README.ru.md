# Свободный модемный стек Titan 2 (MediaTek CCCI)

Драйвер встроенного модема MT6878 (Dimensity 7300, модем поколения 6299) в ядре: всё, через
что Android разговаривает с модемом — запуск и перезапуск модема, порты `/dev/ccci_*`,
`ttyC*`, `ttyCMIPC*` (AT-команды, MIPC для RIL, аудио звонка, IMS), сетевые интерфейсы
`ccmni*` для мобильного интернета, разгрузка данных в модем при раздаче.

В стоке это 8 модулей в разделе `vendor_dlkm`, собранных Unihertz из исходников MediaTek
с их правками. Здесь — тот же стек в открытом виде, вычищенный под одну платформу.

## Что сделано

**Основа:** код CCCI из открытого дерева MediaTek `kernel_device_modules-6.1` (ветка
NothingOSS для MT6878, GPL-2.0), настроенный под Titan 2 (`configs/ccci-mt6878.config`).
Все изменения — наши правки этого открытого кода или код из других открытых деревьев MediaTek.

**Чистка (12 шагов, `src/` — состояние после них):**
- оставлен только MT6878 и модем gen 6299: убран код других платформ и поколений;
- DPMAIF (быстрый канал данных) — только версия v3, без v1/v2;
- убран CLDMA (старый интерфейс, на MT6878 не используется) и его модуль;
- раскрыта условная компиляция под конфигурацию Titan 2, убраны макросы, которые нигде
  не определяются, и функции, которые никто не вызывает;
- собственные `Kbuild` вместо сборки внутри дерева MediaTek.

Итог: на ~13 500 строк меньше (затронуто 111 файлов), стек стал читаемым.

**Как проверялось.** Каждый шаг собирался и сравнивался со стоковыми модулями по функциям:
механические шаги дают 0 отличий в машинном коде. Готовые модули проверены на телефоне:
звонки, SMS и мобильный интернет работают.

**Что пока не так:**
- это только ядро. Прошивка самого модема и служба RIL в Android (`libmtk-ril`, `mdinit`) —
  закрытые, и останутся такими;
- VoLTE нет: в GSI нет службы IMS от MediaTek (стек IMS живёт внутри модема, со стороны
  Android нужна закрытая служба). Это не связано с драйвером;
- найденные при разборе неаккуратности MediaTek (`src/notes/bugs-found.md`) исправляются
  в следующих версиях, в эту не вошли.

**Дальше:** исправления найденных багов, отвязка от остальных закрытых модулей MediaTek и,
как цель, перенос в mainline (подсистема WWAN). Полный список того, что ещё можно открыть, — в
[TODO.md](TODO.md) (на английском).

## Установка (по желанию, только Linux)

Модули заменяют стоковые в разделе `vendor_dlkm`. Готовый образ раздела мы не выкладываем:
кроме 8 наших модулей там ~460 закрытых. Образ собирается из вашего стокового:

1. Стоковый `vendor_dlkm` V01.00.14 — `super.img` из официальной прошивки или снятый
   с телефона (root): `adb shell su -c 'dd if=/dev/block/by-name/vendor_dlkm_a' > vendor_dlkm_a.img`.
   **Сохраните его** — это и есть откат.
2. Модули: `titan2-modem-ccci-<версия>.zip` из релиза (распаковать в каталог).
3. Сборка образа (нужны `erofs-utils` с поддержкой SELinux, `lpunpack`, `simg2img`):

   ```bash
   scripts/make-modem-vendor-dlkm.sh vendor_dlkm_a.img titan2-modem-ccci/ vendor_dlkm-modem.img
   ```

4. Прошивка в fastbootd (там, где `fastboot getvar is-userspace` → `yes`):

   ```bash
   adb reboot fastboot
   fastboot flash vendor_dlkm_a vendor_dlkm-modem.img
   fastboot reboot
   ```

Проверка после загрузки: звонок, SMS, мобильный интернет. Откат — так же прошить стоковый
`vendor_dlkm_a.img`.

## Исходники

`src/` — исходники модулей (`src/VERSION`: проверенная версия `2dcb1fc` с комментариями, переведёнными на английский, и проверкой
длины пакета в `ccmni`, возвращённой к открытому коду MediaTek). Сборка вне дерева ядра против заголовков нашего ядра
(`patches/kernel`) и `Module.symvers` стоковых модулей: стек вызывает экспорты других
закрытых модулей MediaTek, поэтому для сборки нужны их CRC из вашей прошивки.
